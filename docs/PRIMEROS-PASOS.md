# Comprobación previa sin consumir créditos

- `git status --short` y `git remote -v`: confirmar rama y cuenta/repositorio correcto.
- `node --version` y `npm --version` solo si se usará un stack Node.
- Revisar que no se esté usando accidentalmente un proyecto o una sesión de trabajo.
- Si el repositorio ya tiene una app: revisar su `package.json` antes de ejecutar `npm install`.
- No crear un proyecto ni instalar paquetes hasta conocer el track o confirmar que el reglamento permite plantillas.
- No introducir tokens en prompts, archivos del repo o capturas.
